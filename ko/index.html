Fxverter 소개

Fxverter는 브라우저에서 완전히 동작하는 무료 오픈소스 통화 변환기입니다. 141개 세계 통화의 실시간 환율을 제공하며 API 키, 가입, 설치가 필요 없습니다 — 웹사이트를 브라우저에서 열기만 하면 바로 사용할 수 있습니다.

환율은 언제든 전환할 수 있는 세 가지 공개 소스에서 제공됩니다: Frankfurter(유럽중앙은행 기준 환율), ExchangeRate-API, Fawaz Currency API. 환율은 세션별로 캐시되며 29개 UI 언어가 자동 감지되고, 아랍어와 페르시아어는 오른쪽에서 왼쪽 쓰기를 지원합니다.

지원 언어 및 통화

모든 통화 보기 · 환율 가이드

141개 통화의 실시간 환율을 지원하며 드롭다운에서 바로 검색할 수 있습니다. 사용 가능 여부는 선택한 데이터 소스에 따라 다르며, 누락된 쌍은 다른 소스에서 자동으로 가져옵니다:

자주 묻는 질문

이 환율 계산기는 무료인가요?

네. Fxverter는 MIT 라이선스의 완전 무료 오픈소스입니다. API 키도, 가입도, 추적도 없습니다.

환율은 얼마나 정확한가요?

무료 공개 API(Frankfurter를 통한 ECB, ExchangeRate-API, Fawaz)의 참고용 시세로 매일 업데이트됩니다. 빠른 참조에는 적합하지만 거래 전 반드시 은행에 확인하세요.

어떤 통화를 지원하나요?

USD, EUR, GBP, JPY, CNY, TRY, INR, CHF 등 141개 통화. 데이터 소스에 따라 다르며 누락된 쌍은 자동으로 다른 소스에서 가져옵니다.

설치나 계정 만들기가 필요한가요?

아니요. PC든 모바일이든 최신 브라우저에서 웹사이트를 열기만 하면 바로 변환할 수 있습니다. 설치도 계정도 필요 없습니다.

어떤 언어를 지원하나요?

자동 감지되는 29개 언어. 아랍어와 페르시아어는 오른쪽에서 왼쪽 쓰기를 완전히 지원합니다.

제 데이터를 추적하나요?

아니요. 모든 변환은 브라우저에서 로컬로 실행됩니다 — 계정도 추적 쿠키도 없고 공개 환율 API에 대한 익명 요청만 있습니다.
