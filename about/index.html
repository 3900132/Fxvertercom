About Fxverter — Free, Open-Source Currency Converter

Fxverter is a free, open-source online currency converter that runs entirely in your browser. It shows reference exchange rates for over 140 world currencies, requires no API key, no sign-up and no installation — you open the website and start converting.

Why we built it

Most converter sites bury the actual rate under pop-ups, sign-up walls and app-install nagging. We wanted the opposite: a fast, private tool that shows the honest mid-market reference rate first and gets out of the way. The whole product is one static page that works on any device, in seven languages, even offline after installation.

What makes it different

  • No account, no tracking — conversions run locally in your browser
  • Three switchable public data sources: Frankfurter (European Central Bank reference rates), ExchangeRate-API and the Fawaz Currency API
  • 40 major currencies with dedicated pages: live conversion tables, 30/90-day trend charts and currency profiles
  • Plain-language guides that explain how exchange rates actually work
  • Installable as an app (PWA) that keeps working offline with the last known rates

The data

Rates are indicative reference rates from public central-bank and market sources, updated daily. They are the same benchmark you see on Google or in financial news — useful for comparison and planning, not a contractual quote for a specific transfer.

Who is behind it

Fxverter is built and maintained by an independent developer and supported by its users. The complete source code is public on GitHub — anyone can audit it, self-host it or contribute improvements.
